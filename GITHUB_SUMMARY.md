# Solister — GitHub summary

**Short description**

An interactive, browser-based 3D Solar System explorer with planets, moons, orbital paths, time controls, and visual astronomy effects.

**Project summary**

Solister is a self-contained 3D Solar System visualization for exploring the Sun, planets, moons, comets, asteroids, and stars in a shared physical-scale scene. It combines interactive camera and time controls with orbital data, reference body shapes, terrain where bundled global elevation data is available, rings, atmospheres, eclipses, and surface grids. Weather and other rendering effects are illustrative; Solister is an exploration tool, not a mission-planning or precision-observation system.
